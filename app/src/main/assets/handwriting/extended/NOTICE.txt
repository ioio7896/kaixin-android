The conversion procedure is documented in that repository and in Tencent/ncnn's
official ppocrv5 example. Original model terms remain Apache-2.0.

characters.json is a JSON representation of the official 18,383 dictionary
entries, matched in order against the NCNN example's ppocrv5_dict.h at the
same conversion revision. Class zero is CTC blank; an ASCII space is appended
as in PaddleOCR's use_space_char configuration, for 18,385 output classes.
15,907 dictionary entries are Han characters; remaining entries include Latin,
Japanese, punctuation, symbols and emoji. This is not full Unicode Han coverage.

Preprocessing and decoding are original integration code, following the published
48-pixel-high BGR [-1,1] input and CTC output specifications. The app does not
include OpenCV, text detection or document OCR; it renders the captured pen
strokes directly and recognizes a single horizontal handwriting line.
No accuracy or speed evaluation was run for this app integration.
