# 开心离线输入法

开心离线输入法是一款 Android 中文输入法。拼音、手写、词库和表情资源都放在手机里，平时打字不需要联网，也不需要注册账号。

它适合希望在手机或平板上使用离线输入、自己管理词库，或者喜欢调整键盘外观和布局的朋友。项目仍在持续完善，候选排序和手写识别的实际效果会因输入内容、设备和使用习惯而不同。

## 下载和安装

1. 从仓库的 [downloads 目录](downloads/) 下载 `kaixin-android-debug.apk`。这是 Debug 版本，文件较大，因为词库、手写模型和表情资源都随安装包提供。
2. 在 Android 8.0 或更新版本的手机或平板上打开 APK，按系统提示安装。如果系统阻止安装，请按手机提示允许当前来源安装应用。
3. 打开“开心离线输入法”，根据提示进入系统的语言与输入法设置，启用它。
4. 在任意输入框打开键盘，通过系统的键盘切换入口选择“开心离线输入法”。不同品牌的入口名称可能略有不同。

安装后，可以从应用图标进入设置。覆盖安装通常需要新旧 APK 使用相同签名；如果系统提示签名不一致，需要先备份个人词库，再根据系统提示处理。

## 能做什么

### 中文、英文和数字输入

- **拼音输入**：支持 26 键、九宫格，以及小鹤双拼；支持全拼、简拼和混合输入。候选词会结合词库、输入匹配情况和本地使用习惯排序。
- **九宫格选音**：可以选择读音、添加分隔；没有合适候选时保留尚未上屏的输入，方便继续修改。长按数字键可以输入数字。
- **手写和笔画**：支持单字手写和横向单行连写，也可以使用笔画输入。连写时可手动分字，识别后还能逐字修改。
- **其他输入**：支持英文、数字、符号、Emoji，以及简体和繁体输出。电话、日期、时间等输入框会使用相应的数字布局。
- **候选辅助**：可在设置中调整组句、模糊音和纠错等功能；部分功能默认关闭，具体以应用内设置为准。

手写模型和词库都在本机运行，但识别并不保证每次准确。遇到生僻字、字迹重叠或识别不理想时，可以试试单字、分字或笔画输入。

### 常用内容和词库

- **自定义词**：添加、编辑和管理自己的词，也可以导入、导出或备份。备份支持设置口令；请妥善保管口令和备份文件。
- **本地学习**：开启后，输入法可以记住常用词和上下文，帮助调整候选顺序；可在设置里关闭学习或清除记录。
- **快捷短语**：保存常用文字，需要时从键盘面板选择。
- **剪贴板**：历史记录默认开启，可在设置中关闭，也可固定、搜索和删除。默认只在打开剪贴板面板时读取系统当前文本；自动记录需要另行开启。
- **表情**：支持搜索 Emoji，也提供微信表情文字标记。微信表情面板使用图片作预览，实际发送的是文字标记，显示效果取决于接收应用。

### 外观和布局

可以调整主题、明暗模式、键盘高度、字号、按键声音与振动等。手机和平板可使用单手或浮动布局；宽屏还支持分离式 26 键。部分布局与尺寸设置会分别记住横屏和竖屏状态。

## 隐私与本地数据

应用清单不声明网络权限，输入法的词库查询和手写识别在设备上完成。自定义词、学习记录、快捷短语和剪贴板历史保存在本机；卸载、清除应用数据或更换设备前，建议先导出需要保留的词库。词库备份不等同于完整备份所有设置和历史。

隐私模式会暂停学习和剪贴板访问；密码等敏感输入场景也有相应限制。打开隐私模式不会自动删除已有历史，需要时可在设置中手动清除。剪贴板敏感内容过滤依赖系统标记和应用内规则，不能保证识别所有敏感内容，请谨慎保存和分享。

系统启用输入法时可能会提示输入法能够接触输入内容，这是 Android 对输入法的通用提示。建议只从可信来源安装 APK，并自行审阅源码和所用资源。

## 常见问题

**为什么安装包比较大？** 词库、表情素材、手写识别模型和多种设备架构的原生库都放在安装包中，因此不需要首次联网下载这些资源。

**为什么输入后没有想要的词？** 可以检查拼音和读音，换一种输入方式，或者在词库管理中添加自定义词。九键简拼与混拼长词、三四字词提前补全默认开启；提前补全要求至少输入两个完整音节，并优先展示高可信词。部分纠错功能需要在设置中开启。

**换手机后词库还在吗？** 本地数据不会自动跟随设备迁移。请先导出词库，在新设备安装后导入；加密备份需要原口令。

**手写为什么识别不准？** 尽量写清楚，连写时从左往右写一行；必要时使用“分字”或切换单字模式。扩展字符表并不覆盖所有汉字。

**可以作为日常主力输入法吗？** 可以自行尝试，但请根据自己的设备和使用场景判断。Debug 构建成功不代表已经完成所有机型的兼容性、识别准确率或性能验证。

## 技术概览

项目是原生 Android 应用，主要使用 Java，手写识别通过 C/C++ 和 JNI 调用 NCNN CPU 推理。应用包名为 `com.example.offlineime`，最低支持 Android 8.0（API 26），编译和目标 SDK 为 API 35。

| 部分 | 实现方式 |
| --- | --- |
| 键盘与输入服务 | Android `InputMethodService`、自定义键盘视图、候选栏和设置页面 |
| 拼音与候选 | 本地拼音词典和 SQLite 数据库；结合完整匹配、词频、本地学习与上下文进行召回和排序 |
| 手写识别 | 内置 Ismantic/Handwritten 常用字模型及 PP-OCRv5 Mobile 扩展模型，使用 NCNN 在 CPU 上推理；支持单字与横向连写 |
| 繁简转换 | 随应用打包的 OpenCC 字典 |
| 个人数据 | 使用本地存储和 Android Keystore 相关加密机制；词库可导出普通或口令加密备份 |
| 支持架构 | `armeabi-v7a`、`arm64-v8a`、`x86`、`x86_64` |

拼音候选采用首批结果与后台补充查询，兼顾响应与更完整的召回；内部缓存、候选排序、可选纠错和组句规则均为本地实现。具体响应时间与识别准确率没有在这里作保证。

## 从源码构建

需要 JDK 17、Python 3、Android SDK 35、NDK `27.2.12479018` 和 CMake `3.22.1`。项目使用 Gradle Wrapper 8.13 和 Android Gradle Plugin 8.13.2。Android Studio 可以协助安装 SDK、NDK 和 CMake；首次获取构建工具和依赖可能需要联网。

```bash
git clone https://github.com/ioio7896/kaixin-android.git
cd kaixin-android
```

仓库中的下载 APK 使用 Git LFS 管理。若希望克隆后获取该 APK，请先安装 Git LFS；源码构建本身不依赖下载目录中的 APK。NCNN 预编译库位于 `third_party/ncnn/`，如需恢复，参见 [NCNN 说明](third_party/ncnn/README.md)。

在 Android Studio 中打开项目并配置 SDK，或使用命令行构建 Debug APK：

```powershell
.\gradlew.bat :app:assembleDebug
```

macOS 或 Linux 可使用 `./gradlew :app:assembleDebug`。默认输出位置为：

```text
build/offline-ime-app/outputs/apk/debug/app-debug.apk
```

构建过程会从 `lexicon/` 等输入生成拼音数据库并压缩打包，同时校验手写模型资源的 SHA-256。Debug 版本名使用北京时间构建时间戳 `yyyyMMdd-HHmmss`，内部版本码使用相同时刻的 Unix 秒数。发布签名需要通过环境变量提供，详情见 `app/build.gradle`；请勿把签名文件或口令提交到仓库。

## 项目结构

```text
app/src/main/java/       输入法服务、键盘、候选、设置和本地数据
app/src/main/cpp/        手写识别的 JNI 和原生代码
app/src/main/assets/     模型、字典、表情及其他随应用打包的资源
lexicon/                 中文、英文及分类词库
data_sources/            构建词库所需的辅助数据
third_party/ncnn/        NCNN 原生依赖及来源说明
tools/                   词库生成、同步和资源处理工具
downloads/               Git LFS 管理的 Debug APK
```

词库数据库由本地词表生成，安装后不依赖桌面项目或网络。更新桌面词库镜像及单字读音索引的工具位于 `tools/`；来源、许可和具体处理方式应参照相应目录中的说明。
