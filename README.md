# 开心离线输入法

开心离线输入法是一款给 Android 手机用的中文输入法。它可以在没有网络的情况下打字，词库和表情资源随应用一起安装。

## 能做什么

- 拼音输入：中文 26 键、九宫格和小鹤双拼
- 手写和笔画输入
- 英文、数字、符号和 Emoji 输入
- 简体、繁体切换，以及常用词联想
- 自定义词库、常用词学习和剪贴板历史
- 键盘高度、主题、按键声音和震动等设置

## 安装和启用

如果项目的 GitHub Releases 页面提供 APK，可以直接下载；也可以按下方说明自行构建。安装后，在手机的“设置 → 键盘/语言和输入法”中启用“开心离线输入法”，再从键盘切换按钮选择它。

不同手机的设置名称可能略有不同。

## 隐私说明

应用不申请联网权限，输入内容不会发送到服务器。选词学习、自定义词和剪贴板历史保存在手机本地；剪贴板历史默认关闭。密码输入框和隐私模式下不会学习内容，也不会读取剪贴板。

## 从源码构建

需要 Android Studio、Android SDK 和 Python 3。用 Android Studio 打开项目目录并构建 Debug APK，或在 Windows PowerShell 中运行：

```powershell
.\gradlew.bat assembleDebug
```

APK 默认生成在：

```text
build/offline-ime-app/outputs/apk/debug/app-debug.apk
```
