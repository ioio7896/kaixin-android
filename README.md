# 开心离线输入法

项目原创源代码采用 MIT 许可证，详见 [LICENSE](LICENSE)。随项目分发的词库、字典和图形资源可能采用不同许可，详见 [第三方声明](THIRD_PARTY_NOTICES.md) 及各资源目录中的声明。

这是一个从零实现的 Android 输入法 MVP，默认完全离线：Manifest 不声明 `INTERNET`、麦克风、联系人、存储或无障碍权限。中文候选来自本目录的 `lexicon`，词库在安装时随 APK 打包，运行时不访问网络。

## 候选引擎性能优化（2026-10-09）

- 首屏与补充候选使用两条可取消的工作线：首屏线程使用普通优先级，先生成最多 24 条可点击候选；补充线程处理完整检索、纠错、姓名、组句和九键路径。候选按当前输入版本绑定，按下时保留条目快照，避免后台更新选错词。九键候选在路径准备前发布。
- 全拼、九键和小鹤双拼共用高频单字内存索引：字码、词频和读音编号存入基本类型数组，各编码桶共享行编号；造词先查询内存单字，展开时补齐最多 512 条。单字、前段词组和低频展开检索分开，词组前段结果可复用缓存。
- 数据库新增独立单字表与覆盖索引，词组全拼／简拼造词查询拆成独立索引查询。数据库 schema 升至 8，词库版本 `2026100901`；随 APK 重建，安装后替换旧版本数据库。
- 基础词库、组句词图、拼音路径与个人候选分别缓存，学习和用户词变动不再清空基础词库及普通拼音路径；缓存同时限制估算字节和条目数，收到内存压力回调时释放查询缓存。缓存键只包含相关查询设置，减少外观设置造成的重复检索。
- 全拼／九键解析复用稳定前段，修改尾音节时重新计算受影响范围；组句按目标音节推进，复用前段词图与最终束状态，读音、查询设置或上下文版本变化时重新计算。减少逐条排序，个人分数和上下文分数一次合并，双拼路径与界面样式复用。
- 可选性能日志新增首屏可点击、首屏绘制耗时，冷／热状态与全拼／九键分别汇总 P50/P95/P99，不记录输入内容。16ms 等数值属于优化目标，未进行手机耗时实测。
- APK 版本 `0.3.2`（versionCode 11）。遵循本目录 AGENTS.md，不运行代码测试，仅构建 debug APK。

## 生词后半段高频单字候选（2026-10-09）

- 整词 a+b 不在词库时，普通输入和造词草稿均可选择前段 a；保留 b 的编码后，优先展示 b 首音节的高频单字，继续逐字或逐段选完。
- 单字与词组分别检索，避免大量词组占满检索额度而遗漏高频单字；普通输入缺少完整候选时补充可选择的前段候选。
- 后续候选沿用剩余拼音路径限定，支持全拼、九键和小鹤双拼；选完前段后保留后段已选双拼读音，候选栏保持单字优先。

## 自选拼音造词与词库管理（2026-10-08）

- 新增“键盘布局 → 造词”入口，也可在工具栏自定义入口中选择“造词”。造词过程的选字保存在本次输入框的草稿内，完成后统一保存并上屏；支持中文 26 键、九键及小鹤双拼，逐字或逐段选择，撤销、删除片段、局部重选字和修改读音。
- 九键候选按实际消耗编码保留后半段。造词使用独立的前段检索，完整拼音路径不存在整词时仍可选单字；展开页保留最多 512 条候选，提供起笔笔画筛选和手写补字后的多音字读音确认。修改已选片段时保留其他已选片段和剩余拼音限定。
- 主动保存的词语采用独立、加密的本机词库，完整读音保留音节边界，读音、快捷别名、分类和固定状态分别管理；保存默认不固定，仅匹配对应读音或别名时固定生效。重复保存合并读音和别名，主动保存不受自动学习开关影响，密码／禁止个性化学习输入框和隐私模式继续禁止保存。
- 普通输入在同一段编码中逐段选完后，提供“记住刚输入的整词”；候选长按支持保存和打开词条编辑器。没有明确确认的组合不会额外自动合并入库。
- “设置 → 词库管理”新增管理页：搜索汉字、拼音或别名，按主动保存、学习记录、固定和分类筛选；编辑词语、多个读音、别名和固定状态；分别清除学习记录或主动保存词，词条保存和删除提供 10 秒撤销。编辑词语时迁移旧学习统计，旧用户词库格式继续兼容。
- 自定义词支持 JSON 导入导出和口令加密备份，系统文件选择器访问用户指定文件，无新增存储权限。加密备份使用 PBKDF2-HMAC-SHA256 与 AES-GCM，口令至少 8 个字符；导入先预览，确认后一次合并，失败保留原词库。备份范围为主动保存的词、读音、别名、分类和固定状态，不包括上下文模型与自动学习统计。
- 选词学习、自定义词写入、导入导出在有序后台线程处理；保存失败保留草稿，切换输入框后不把旧草稿误上屏。APK 版本 `0.3.0`（versionCode 9）。遵循本目录 AGENTS.md，不运行代码测试，仅构建 debug APK。

## 构建

使用 Android Studio 打开此目录即可。工程没有第三方运行时依赖。构建时会由 `tools/build_lexicon_db.py` 把文本词库预编译为 SQLite 索引，安装后直接复制使用，避免首次启动逐条导入。构建环境需要 Python 3。

在 Windows PowerShell 中也可以使用已安装的 Gradle：


## 本地候选排序评估

`tools/evaluate_candidate_ranking.py` 使用由 `lexicon/` 生成的本地 SQLite 词库，读取带人工期望词的 JSONL 案例，比较纯语料排序与个人频次/上下文加权后的 Top-1、Top-5 和首选错误率。评估数据只在本机处理，不记录真实键入内容。可从示例集开始：

```powershell
python tools/evaluate_candidate_ranking.py tools/candidate_ranking_cases.example.jsonl
```

扩充案例时，为每个候选词填写可选的 `personal`（选择次数、距上次选择天数、跳过次数）和 `context`（二元/三元转移次数、距上次使用天数）数据，以离线比较权重变化。

本次回归使用 Pixel_10a（Android 17 / API 37）模拟器：安装、启用、切换输入法，以及 9 键连续输入 `64426`、拼音路径消歧和首候选“你好”均通过；输入前后键盘位置保持稳定。模拟器带硬件键盘时可执行 `adb shell settings put secure show_ime_with_hard_keyboard 1` 让软键盘显示。

安装后在系统设置 → 系统 → 键盘 → 屏幕键盘中启用“开心离线输入法”。没有连接设备时也可以只进行构建验证。
